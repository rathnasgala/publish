# Gala publish distribution

This repository tree is generated by `action/scripts/stage-release-tree.js`. Do not edit the
distribution repository directly. Source changes belong in the Gala monorepo and are reproduced,
tested, reviewed, and staged from there.

The staged `v1/validation` source exists only so the release workflow can publish the exact
`@rathnasgala/content-validation` version through npm trusted publishing. Action consumers execute
the committed `dist/index.js` bundle; they do not install or load `v1/validation` at runtime.

Immutable `vX.Y.Z` tags identify releases. The moving `v1` tag advances only after release
verification and canary approval.

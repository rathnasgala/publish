# @rathnasgala/content-validation

This package contains the deterministic content, repository, and Prism validation contracts used by
Gala's CLI and publishing workflow. It is public so the exact rules used during publication remain
inspectable and reproducible.

Most developers do not need to call it directly. To experience the complete authoring and publishing
workflow, visit [gala67.com](https://gala67.com) or create a publication:

```console
npx --yes @rathnasgala/cli@latest init field-notes
```
